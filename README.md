# DEMI VR PCB – Calais & Marck

Un programme pilote de formation en électronique, PCB, IoT, programmation STM32/ESP32 et réalité virtuelle immersive avec Meta Quest 3S.

## 🎯 Objectif

Former les jeunes (12–25 ans) aux métiers de l'électronique, du numérique et de la réalité virtuelle à travers une approche pédagogique concrète et immersive.

## 🌐 Public cible

- Jeunes de 12 à 25 ans
- Écoles et établissements d'enseignement
- Missions locales
- Collectivités territoriales
- Associations
- Financeurs et entreprises

## 📈 Parcours pédagogique

1. **Niveau 1** – LED et résistances
2. **Niveau 2** – Capteurs
3. **Niveau 3** – STM32
4. **Niveau 4** – ESP32 IoT
5. **Niveau 5** – PCB
6. **Niveau 6** – Projet final

## 🚀 Déploiement

### Sur GitHub Pages

1. Allez dans les paramètres de votre repository
2. Activez **GitHub Pages**
3. Sélectionnez la branche `demi-vr-pcb-website`
4. Votre site sera accessible à : `https://sahalabdillahi150-png.github.io/probable-drone-energy/`

### Localement

```bash
# Clonez le repository
git clone https://github.com/sahalabdillahi150-png/probable-drone-energy.git

# Naviguez dans le dossier
cd probable-drone-energy

# Ouvrez index.html dans votre navigateur
open index.html
```
